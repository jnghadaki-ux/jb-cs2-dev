# SWBS Ultimate Jailbreak for Counter-Strike 2

A CounterStrikeSharp port of hlstriker's SMPlugins **Ultimate Jailbreak** (Swoobles / SWBS CS:GO) plus the server plugins and
admin tools that ran with it, rebuilt for CS2.

**Credits:** Gdaki — designed after HlStriker, Swbs development/lead admins.

* Status: `0.9.0` test build — builds cleanly, all core systems implemented, **not yet verified on a live server**
  (see PROJECT_STATUS.md, FEATURE_INVENTORY.md).
* Install / build: BUILD_AND_TEST.md · In-game test checklist: TEST_PLAN.md · Limits: FEATURE_GAPS.md, COMPATIBILITY.md
* Architecture: ARCHITECTURE.md, docs/DEVELOPER.md · Decisions: DECISIONS.md · Next session: SESSION_HANDOFF.md
